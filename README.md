# V2Ray VLESS/VMess/Trojan Server -- Telegram Bot Admin

خادم V2Ray (VLESS / VMess / Trojan عبر WebSocket) تتم إدارته **بالكامل عبر بوت تلقرام**.
لا توجد أي واجهة ويب أو تسجيل دخول -- البوت هو نقطة التحكم الوحيدة، ويعمل حصريًا مع معرف الأدمن المحدد في `TELEGRAM_ADMIN_CHAT_ID`.

## المزايا

- إنشاء تكوينات VLESS / VMess / Trojan من داخل تلقرام (اختيار البروتوكول + مدة صلاحية مستقلة لكل تكوين + حد استهلاك بالجيجابايت).
- عرض/تعديل/حذف التكوينات، مع رابط الاتصال وصورة QR يُرسلان مباشرة في المحادثة.
- عرض حالة الخادم (تشغيل/إيقاف V2Ray، القرص، الذاكرة، عدد العملاء النشطين/المنتهية/الموقوفة).
- تشغيل/إيقاف/إعادة تشغيل V2Ray (بدون انقطاع، عبر تبديل slot A/B) من تلقرام مباشرة.
- عرض آخر سجلات التشغيل.
- أي مستخدم آخر غير الأدمن يُتجاهل تلقائيًا.

## التشغيل محليًا

**المتطلبات:** Node.js 22+, curl, unzip (لتحميل ثنائي V2Ray تلقائيًا)

1. تثبيت الاعتماديات: `npm install`
2. انسخ `.env.example` إلى `.env` واضبط:
   - `APP_URL` — نطاق الخادم العلني (يُستخدم لبناء روابط التكوين)
   - `TELEGRAM_BOT_TOKEN` — توكن بوت تلقرام
   - `TELEGRAM_ADMIN_CHAT_ID` — معرف حساب تلقرام المسموح له وحده بالتحكم
3. تشغيل التطبيق: `npm run dev`
4. من تلقرام: أرسل `/start` للبوت لعرض القائمة الرئيسية.

## النشر عبر Docker

```bash
docker build -t v2ray-bot .
docker run -e TELEGRAM_BOT_TOKEN=... -e TELEGRAM_ADMIN_CHAT_ID=... -e APP_URL=https://your-domain.com \
  -p 3000:3000 -p 10080-10082:10080-10082 -p 10090-10092:10090-10092 v2ray-bot
```

راجع `Dockerfile` و`docker-compose.yml` لمزيد من التفاصيل.
